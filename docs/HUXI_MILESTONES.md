# 虎溪 m1–m5 版本与资料说明

当前版本 m5，发布日期 2026-11-11。最初安排的五批展示建模已完成；后续局部校核使用 m5.1、m5.2 等版本名，新增范围另定批次。

## 分批成果

| 批次 | 范围 |
| --- | --- |
| m1 | FABDEM 基础地形；图书馆、综合楼、艺术楼、学生活动中心 |
| m2 | 一教、信息技术科研楼、理科楼、工科大楼 |
| m3 | 体育馆与附馆、田径场、梅园/松园/兰园运动场；撤回活动中心不受资料支持的白色楼翼和额外台阶 |
| m4 | 三处食堂、校医院与既有宿舍记录的窗洞、阳台、门厅和接入路 |
| m5 | 科学中心、储能大楼、荷园新食堂及西南景观，道路、平台与新入口导航 |

## 已核对事实与展示估算

| 对象 | 公开资料支持 | 本版估算与待核部分 |
| --- | --- | --- |
| 科学中心 | 最高十层、47.7 米，地上约 18.25 万平方米；低裙楼与高低塔楼组织庭院 | 各塔楼轮廓、分高、窗距及具体入口地坪 |
| 储能大楼 | 校方封顶报道为地上八层、35.85 米、约 7.3 万平方米；环评给出场地位置、用地及交通组织 | 双庭院各翼尺寸、未见立面和微地形；目前实际投用状态待核 |
| 荷园新食堂 | 2026 年 7 月封顶报道：地上三层、地下一层、16.7 米、7979 平方米，计划 2027 年投用；航拍显示两个采光井 | 展示计划完成形态，暂放工科楼南侧；准确总平面位置、竣工外墙及入口待核 |
| 西南景观 | 校方照片显示园路、弧形低坐凳、木座椅、灯杆和种植 | 校内空地的局部布局为照片启发的示意，尚未与景观竣工图配准 |
| 生活区 | 食堂/医院服务资料、已有地图与影像 | 宿舍楼号、部分手工轮廓、入口及总楼高仍需逐栋校核 |

储能楼环评版本记载 34.45 米，本版采用较新的校方封顶报道 35.85 米。m5 移出与储能楼推定范围冲突的四条旧手工宿舍占位，保留 34 条宿舍记录；此数量是本版记录数，不能当作实际校园宿舍总数。

## 地形与通行

地形使用约 30 米原始分辨率的 FABDEM V1-2，重采样为 6 米展示网格。平台、庭院、台阶、缓坡与微地形经过局部拟合。局部标高与入口位置属于展示估算，适用于校园浏览与纠错参考。

m5 保留已有湖面及其他建筑平台，新增三处入口和景观通行路线。导航终点绑定到本版暂估入口；数据中保留 `confirmed:false` 标识。架空层展示可见开敞构件，室外碰撞按建筑轮廓处理，尚未制作室内导航。

## 验证

- TypeScript 检查、生产构建及浏览器资源加载。
- 三处近/远景模型、平台与网格高度、庭院开口及保留建筑冲突检查。
- 41 条建筑入口接入路，加上景观环路、连接路和中央铺地支路，共 44 条路线的实际步行检查。
- 三处新地标导航终点、沙坪坝 A/虎溪往返、中英文直链及 390×844 手机视图。
